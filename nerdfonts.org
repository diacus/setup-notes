#+title: Nerd Fonts

Iconic font aggregator, collection, and patcher. See the [[https://www.nerdfonts.com][official
site]] for details

* How to install Nerd Fonts
Depending on your needs or choices go to [[https://www.programmingfonts.org/][programming fonts]], to have an
idea of what to expect from each available font.

For now I choose =Hasklug Nerd Font=, so I downloaded it under my
[[file:~/.local/share/fonts][users's fonts directory]].

#+begin_src shell :dir ~/.local/share/fonts
mkdir Hasklug
cd Hasklug

wget -q -O Hasklug.zip https://github.com/ryanoasis/nerd-fonts/releases/download/v3.0.2/Hasklig.zip
unzip Hasklug.zip
rm Hasklug.zip
#+end_src

#+name: install-hasklug-nerd-font
#+begin_src emacs-lisp
  (require 'url)

  (let* ((font-raw-url
          "https://github.com/ryanoasis/nerd-fonts/releases/download/v3.0.2/Hasklig.zip")
         (dest-dir "~/.local/share/fonts")
         (dest-file (concat dest-dir "/Hasklug.zip")))
    (unless (file-directory-p dest-dir)
      (make-directory dest-dir t))
    (url-copy-file font-raw-url dest-file t)
    (start-process "unzip-process" "*unzip-output*"
                   "unzip" dest-file "-d" (concat dest-dir "/Hasklug")))
#+end_src

In case you want to get rid of the font you installed, you just need
to delete the folder that contains it

#+name: uninstall-hasklug-nerd-font
#+begin_src shell :dir ~/.local/share/fonts
rm -rf Hasklug
#+end_src
