#+title: Tmux Settings

Before configurating [[https://github.com/tmux/tmux/wiki][tmux]], make sure you have available the following packages
in your system:

- [[https://github.com/tmux/tmux/wiki][Tmux]] (>= v1.9)
- [[https://git-scm.com/][Git]]
- [[https://magit.vc/][Magit]]

* Tmux Configuration
I have a public gist with the contents of =$HOME/.tmux.conf= file to install it
just run the code block below.

#+name: tmux-gist
: https://gist.githubusercontent.com/diacus/60cdda7c425f864acfee309973abdda7/raw/c4a7ff95804a35cc98656c50002376d3f6bdd9dc/.tmux.conf

#+begin_src emacs-lisp :var tmux-conf-url=tmux-gist
  (let ((tmux-conf-file (expand-file-name ".tmux.conf" (getenv "HOME"))))
    (url-copy-file tmux-conf-url tmux-conf-file)
    (message (format "Tmux configuration installed in %s" tmux-conf-file)))
#+end_src

Before to start tmux for the very first time, proceed to install the plugin
manager.

* Tmux Plugin Manager
Installing the plugin manager requires running v1.9 or higher. For details see
the repository on [[https://github.com/tmux-plugins/tpm][Github]].

#+name: install-tpm
#+begin_src emacs-lisp
  (require 'magit)

  (let ((tpm-url "https://github.com/tmux-plugins/tpm")
        (tpm-dir (expand-file-name ".tmux/plugins/tpm2" (getenv "HOME"))))
    (magit-clone-regular tpm-url tpm-dir nil))

#+end_src

After entering tmux for the very first time, you will need to hit =C-c= + =I=
right away to tell TPM to install the missing plugins.
